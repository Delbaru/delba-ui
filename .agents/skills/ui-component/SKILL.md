## 2. PRE — до первой строки кода

Определи до изменения; в плане назови решения, существенные для задачи:

1. **Место.** Это библиотека (форма и поведение) или проект (продукт, скины, словари)?
   Бизнес-существительное в имени — значит проект.
2. **Инвентарь ядра.** Открыт ли [`docs/core.md`](../../../docs/core.md)? Чего из нужного там ещё нет?
3. **Договор.** Какие токены проекта понадобятся и все ли они уже в `theme/tokens.default.scss`?

## 3. Красные линии — нарушение любой = переделка

1. **Ни одного импорта наружу папки.** Сторож `tools/check-boundary.mjs`.
2. **Цвет, шрифт, длительность, тень — токеном проекта.** Новый токен — сразу в стартовую тему.
3. **Респонсив — кортеж `[desktop, mobile, tablet]`; `null` = пропуск брейкпоинта.**
   «Как на desktop» — значением. Внутри библиотеки нормализуй `resolveResponsive`.
4. **Строгий TypeScript: без `any`, `!`, `@ts-ignore`, `eslint-disable`.** Индексация массива даёт
   `T | undefined` — это проверяется, а не утверждается.
5. **Пропы коробки — из `src/core/layout/box.ts`**, а не свои копии отступов и размеров.
6. **`ref` — обычный проп (`WithRef`), склейка — `useMergedRefs`.** `forwardRef` не используем.
7. **Классы примитивов — глобальные `ui-*`.** CSS-модуль — только крупному виджету.
8. **Слои: покой в `ui.components`, пропы в `ui.utilities`, состояния в `ui.states`.**
9. **SCSS — только непропсовое** (overflow, transform, transition, z-index, opacity,
   псевдоэлементы, селекторы состояний). Отступ, размер, радиус, фон — пропом.
10. **`@media` ради размера — ошибка**: это кортеж. Законные медиазапросы берутся из `MEDIA_QUERY`
    или миксинов ядра.
11. **Повторяющийся рецепт SCSS — миксин в `src/core/_mixins.scss`**, а не копия.
12. **`z-index` — токен `--z-*`**, если это этаж приложения, а не порядок двух соседних узлов.
13. **Движение уважает `prefers-reduced-motion`; страховка — `MOTION_END_BUFFER_MS`.**
14. **JSDoc у каждого публичного пропа.**
15. **Публичное только добавляют.** Ломающая правка — коммит с пометкой `BREAKING:` и объяснением,
    как перейти. Неиспользуемый, но рабочий компонент НЕ удаляют: он живёт ради других проектов.

Декоративная рамка не должна забирать псевдоэлементы потребителя или клиповать его
контент. Для градиента проверь прозрачный центр, радиусы, responsive и совместимость
с hover/focus/ссылкой; повторяемую механику держи в общем компоненте (GradientBorder).

При упрощении API сокращай общую повторяемую механику, сохраняя видимыми решения
потребителя. Факты и boolean (`useScroll().y`, `down(32)`) позволяют обычному React
выбирать state; ядро не знает проектных compact/hide и не задаёт их стили.
Не заменяй if/useState системой команд, render-обёрткой или ручкой set стилей без
самостоятельной задачи. Пресет — готовый набор настроек; размер/геометрия — size/layout.
Сохранённые DOM/ref/events/SSR/reduced motion важнее уменьшения числа строк.
Обычный потребитель выбирает намерение публичным API, не копирует формулы
и алгоритмы. Инкапсулируй механику у владельца поведения; расширенный callback
сохраняй для особых случаев. Набор пресетов обнаружим через экспорт, автодополнение
и описания, без угадывания строк. API читается без знания реализации.
Не создавай пресет или обёртку, если они лишь переименовывают простое значение.

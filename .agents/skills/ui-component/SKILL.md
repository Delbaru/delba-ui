# UI-компонент — короткий маршрут

Выбери режим по [AGENTS](../../../AGENTS.md).
**FAST:** если известна локальная подпись/строка без изменения поведения,
прочитай точное место, измени, проверь diff и локальный результат — не исследуй
ядро и потребителей без конкретного риска.
**FOCUSED/DEEP:** при изменении поведения, API или архитектуры прочитай
[принципы](../../../docs/specs/architecture/principles.md), нужную
[спецификацию](../../../docs/specs/README.md) и страницу
[компонента](../../../docs/specs/ui/components/README.md).
Изменённый публичный API требует актуального примера и проверки потребителя.

- DelbaUI владеет общей механикой; продуктовые D-компоненты, бизнес-роли и темы
  принадлежат потребителям. Не импортируй CMS или сайт внутрь кита.
- Сохраняй управляемые состояния, DOM ref, композицию событий, SSR, клавиатуру,
  фокус и reduced motion. Для обычного пропа не создавай новый dispatcher.
- Общие layout/motion/refs и миксины переиспользуй из существующего core.
  Новая обёртка оправдана отдельной ответственностью, не сокращением числа строк.
- Factory сохраняет точный словарь generic до результата; props потребителя не
  расширяют его через inference (`NoInfer`), отсутствие словаря типизируется пустым.
- При новом компоненте смотри [authoring](../../../docs/authoring.md);
  для переиспользования [core](../../../docs/core.md).
- Проверки выбирай по [ui-verify](../ui-verify/SKILL.md) и реальному риску,
  не по количеству затронутых TSX.

Подробные инварианты Input, public API, hooks, структуры, styles и ранее
подтверждённых отказов — в [развёрнутом договоре](references/advanced.md).
Не загружай его целиком в FAST.

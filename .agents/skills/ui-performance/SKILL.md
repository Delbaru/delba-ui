# Производительность Frontend

Начни с одного сценария и наблюдаемой задержки. Сверь React, layout и paint
отдельно. Для scroll зафиксируй настоящий viewport, активный ввод и позднее
изменение высоты контента. Для кадров проверь вычисленные стили и trace.

После разрешения сравни исходную и новую версии по одинаковой сборке,
данным, viewport и действиям. Сохрани метрику и условия во внешнем delba-plan.
Ресурсы и разрешения — [разработка](../../../docs/development.md).
Проверка — [ui-verify](../ui-verify/SKILL.md).

# Приёмка Frontend

Применяй shared `delba-verify`. Режим, команды и ручная UI-приёмка описаны в
[разработке](../../../docs/development.md). Команды бери из
[package.json](../../../package.json) и текущих [module actions](../../../tools/module.mjs).

Сверь изменённый публичный prop с типами, DOM, событиями и разными
потребителями. При миграции сверяй публичные импорты, обязательные файлы
компонента и подключение его stylesheet. Сверь каналы Motion с типом и
фактическим хостом. Проверь расположение тестов и владельца generated проекций.
В SOURCE ONLY фиксируй чтение исходников и отдельно
отложенную исполняемую приёмку. Засчитывай выполненную проверку в её реальном охвате.

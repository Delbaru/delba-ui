# Skeleton

Текущий договор, сверенный по исходнику; runtime-проверка отдельно.

## Назначение и применение

Заглушка на месте ожидаемого контента. Форма должна соответствовать геометрии результата, а не произвольно заполнять пустоту. Состояние загрузки и момент замены принадлежат вызывающему компоненту.

## Основной API

- `w`, `h`, `r`, `gap` — responsive-геометрия, `rows` — число полос, `className` — оформление.
- Умолчания исходника: ширина `100%`, высота 16, радиус 8 и gap 8 действуют на всех диапазонах. Многострочный вариант сохраняет вертикальное направление и ширины строк на mobile/tablet.
- `rows={1}` — полоса; несколько строк образуют абзац с укороченной последней строкой.
- Skeleton не предоставляет собственного сетевого состояния, текста статуса или универсального DOM/ref API.

## Пример

```tsx
import { Skeleton } from '@delba/ui';

export function SkeletonExample() {
  return (
    <div role="status" aria-label="Загружаем описание">
      <div aria-hidden="true">
        <Skeleton
          w={['100%', '100%', '100%']}
          h={[16, 16, 16]}
          gap={[8, 8, 8]}
          r={[4, 4, 4]}
          rows={3}
        />
      </div>
    </div>
  );
}
```

## Приёмка

Сопоставь заглушку с реальным результатом на всех полосах; при замене нет скачка и лишних сообщений для скринридера. Для перехода skeleton удерживается до конца ухода. Проверь reduced motion и повторную загрузку, а не только первый кадр.

## Устройство и проверка рефакторинга

Одинокая полоса и контейнер абзаца получают маркер Skeleton из собственного SCSS; блик принадлежит классу stripe, поэтому абзац не получает второй общий блик поверх строк. Полные responsive-умолчания действуют на всех полосах. useAnimationVisibility управляет унаследованным animation-play-state: блик останавливается вне экрана и в скрытом документе.

Корень использует собственный styles.Name без глобального класса-дубля. Пустой селектор может исчезнуть при компиляции, поэтому наличие отдельного DOM-класса не гарантируется; фиктивные CSS-декларации для его сохранения запрещены. Проверка типов и unit-тесты не подтверждают внешний вид: финальная браузерная приёмка выполняется после объединения всей библиотеки.

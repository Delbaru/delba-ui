# Каталог публичных компонентов

Отдельная страница на каждый публичный React-компонент корневого `@delba/ui`: назначение, применение, основной API, самостоятельный пример, ограничения и критерии приёмки. Имена сверяются с [публичным входом](../../../../src/index.ts), а не с именами папок.

Это справочник текущего договора по исходникам, не свидетельство браузерной проверки всего набора. TSX-примеры описывают использование примитивов: в приложении сначала выбирай его D-компоненты со скинами, размерами и пресетами. Условия подключения Next, темы, генератора и стилей — в [README библиотеки](../../../../README.md).

## Полнота и сопровождение

Состав каталога — 40 публичных компонентов, включая providers и публичные составные части AccordionItem, GridItem и Carousel controls. Хуки и функции не считаются компонентами; их применение описано рядом с владельцем. Внутренние CollapseWrap, Calendar, InputFeedback и другие не экспортированные корнем детали не становятся публичным API из-за наличия TSX-файла.

Новый публичный компонент получает отдельную страницу и строку здесь в той же задаче. При изменении пропсов, defaults, жизненного цикла или exports обновляй страницу и сверяй пример с типами; при удалении/переименовании следуй договору совместимости. Не переноси сюда весь JSDoc, CSS и устройство каждого помощника: ссылки на источник сохраняют одного владельца подробностей.

Пример должен содержать публичные импорты и необходимое состояние/контекст, не использовать несуществующий проп или скрытый глобальный обработчик. Next client boundary обязателен для интерактивных примеров; медиаресурсы и токены, принадлежащие приложению, обозначаются явно. Для документации достаточно сверки exports, типов примеров и ссылок; соответствие интерактивного поведения подтверждается отдельной [приёмкой](../../verification/acceptance.md).

# TabTrack

Бегунок повторно измеряет активный элемент при изменении размеров, порядка или
состава DOM и атрибута state. Перестановка keyed children при неизменном value
не требует remount; замена активного узла переключает ResizeObserver на новый узел.
Наблюдение структуры ограничено childList/characterData и атрибутом state:
собственные записи style/data-thumb не создают цикл измерений.

Дорожка с одним движущимся индикатором выбранного элемента.
Используй для визуальной отметки выбора среди соседних кнопок/вкладок.
Компонент не управляет выбором и сам не реализует доступные tabs.

## Основной договор

| Проп | Значение |
|---|---|
| `value` | Обязательная строка/null; изменение запускает новое измерение |
| `thumb` | Обязательный вариант: primary, white или line |
| `children` | Кнопки/вкладки; выбранный узел должен иметь state active |
| Пропсы Flex | Раскладка и оформление самой дорожки; ref исключён из API |

Координаты берутся из первого потомка `[state~='active']`, не из сопоставления value
с ключом узла. `value=null` предназначен для отсутствия выбора: убери active с детей.
У индикатора нет отдельного default-варианта.

## Пример

```tsx
'use client';
import { useState } from 'react';
import { Button, TabTrack } from '@delba/ui';

export function Mode() {
  const [value, setValue] = useState('list');
  return <TabTrack value={value} thumb="line" role="group"
    aria-label="Вид списка" gap={[8, 8, 8]}>
    {['list', 'grid'].map((mode) =>
      <Button key={mode} state={value === mode ? 'active' : undefined}
        aria-pressed={value === mode} onClick={() => setValue(mode)}>
        {mode === 'list' ? 'Список' : 'Сетка'}
      </Button>
    )}
  </TabTrack>;
}
```

## Состояния и ограничения

Первая постановка индикатора и появление после отсутствия выбора происходят
без перелёта; последующие смены и изменение размеров используют переход.
ResizeObserver следит за дорожкой и активным узлом; геометрия учитывает offsetParent,
чтобы transform родителя не искажал измерение.
Три части индикатора сохраняют форму углов при растяжении.
Потребитель отвечает за семантику group/tabs, клавиатуру и выбранный state.
Не оставляй несколько active-потомков.

## Приёмка

Проверь смену разных по ширине пунктов, отсутствие выбора, повторное появление,
resize и догрузку шрифта. В анимируемом родителе края индикатора должны совпадать
с выбранной кнопкой. Проверь начальный SSR-вид и reduced motion.

## Устройство и проверка рефакторинга

TabTrack.tsx собирает только дорожку и три части индикатора. TabTrack.model.ts владеет измерением и ResizeObserver в ownerDocument; public value остаётся единственным сигналом выбора. Корень использует styles.TabTrack из собственного SCSS-модуля. Малые части бегунка остаются в JSX: у них нет отдельного жизненного цикла.

Корень использует собственный styles.Name без глобального класса-дубля. Пустой селектор может исчезнуть при компиляции, поэтому наличие отдельного DOM-класса не гарантируется; фиктивные CSS-декларации для его сохранения запрещены. Проверка типов и unit-тесты не подтверждают внешний вид: финальная браузерная приёмка выполняется после объединения всей библиотеки.

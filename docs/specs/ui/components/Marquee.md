# Marquee

Статус требований: базовый договор. Проверено чтением исходников;
визуальная бесшовность и жесты требуют отдельного браузерного прогона.

## Назначение и выбор

Непрерывная горизонтальная лента с копиями содержимого и перетаскиванием.
Подходит для повторяющегося ряда логотипов или коротких элементов.
Для дискретных слайдов и выбора страницы используй [Carousel](Carousel.md).

## Основной договор

- `children` — исходные элементы, которые повторяются компонентом.
- `as` — тег каждой копии: `div` по умолчанию либо `ul` для дочерних `li`.
- `gap` — responsive-зазор `[desktop, mobile, tablet]` между элементами и копиями.
- `speed=40` — скорость в px/с; `reverse=false` меняет направление на противоположное.
- `paused=false` — управляемая пауза, `draggable=true` — drag с инерцией.
- `fade=false` — затухание по краям.
- Остальные props — от Flex, кроме `ref`, `as`, `dir`, `gap`, `children`.
  Публичного DOM ref у этого компонента нет.

## Минимальный пример

```tsx
'use client';
import { useState } from 'react';
import { Marquee } from '@delba/ui';

export function Brands() {
  const [paused, setPaused] = useState(false);
  return <section>
    <button type="button" onClick={() => setPaused(!paused)}>
      {paused ? 'Продолжить' : 'Пауза'}
    </button>
    <Marquee paused={paused} gap={[24, 16, 24]}>
      <span>Первая марка</span><span>Вторая марка</span>
    </Marquee>
  </section>;
}
```

## Состояния и ограничения

Наведение мыши и фокус внутри приостанавливают автоматический ход.
Копии скрыты от доступности через `aria-hidden` и `inert`; исходный ряд доступен.
При reduced motion копии скрываются, содержимое переносится в строки без движения.
`paused` не отключает drag. Явную кнопку паузы предоставляет потребитель.
Число копий ограничено 12; не подменяй геометрию окна растягиванием по длине ленты.

## Критерии приёмки

Проверь короткий ряд, resize, шов, паузу/продолжение и оба направления.
Drag не должен активировать ссылку после броска; обычный клик должен работать.
Проверь фокус, reduced motion и отсутствие повторов в дереве доступности.

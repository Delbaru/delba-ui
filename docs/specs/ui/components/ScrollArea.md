# ScrollArea

Текущий договор, сверенный по исходнику; runtime-проверка отдельно.

## Назначение и применение

Нативная прокручиваемая Flex-область с оформлением скроллбара и краевым fade. Ref и события относятся к самому viewport. Заголовок и неподвижный footer размещаются снаружи, а не внутри прокрутки.

## Основной API

- `axis="y"` по умолчанию; также `x`.
- `fade={false}` по умолчанию; `true` включает общий scrollFade выбранной оси.
- `scrollbar` настраивает штатную полосу через ScrollbarOptions, не padding содержимого.
- Наследует FlexProps кроме `scrollFade`; размеры области задаются layout-пропсами. Без ограниченной высоты вертикальная область может просто растянуться.
- `className` / `style` дополняют корень, но не заменяют общий механизм прокрутки.

## Пример

```tsx
import { ScrollArea } from '@delba/ui';

export function ScrollAreaExample() {
  return <ScrollArea h={[240, 180, 240]} fade aria-label="История заказа"
    tabIndex={0}>
    <p>Заказ принят</p><p>Подготовка модели</p><p>Печать</p>
  </ScrollArea>;
}
```

Содержимое примера короткое: реальный overflow зависит от данных. Визуально проверь и короткий, и длинный список.

## Приёмка

Прокрутка работает мышью, touch и клавиатурой; начало/конец и fade соответствуют доступному содержимому. Фокусируемый viewport имеет имя. Маска не обрезает портал/оверлей; footer остаётся неподвижным и доступным при малой высоте окна.

## Внутренняя композиция

ScrollArea остаётся коротким адаптером Flex. scrollbarProps отвечает за настройки
нативной полосы, useScrollbarActivity подключает существующего общего владельца
наблюдения, scrollFade принадлежит Flex. Второй scroll engine или дополнительный
viewport не создаётся. Собственный ScrollArea.module.scss содержит корневой селектор;
маркер ScrollArea сохраняется даже при удалении пустого CSS-селектора сборщиком.
ui-scroll-area и generated utility-классы сохраняют прежний договор темы.

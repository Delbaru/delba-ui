# Icon

Текущий договор, сверенный по исходнику; runtime-проверка отдельно.

## Назначение и применение

Inline SVG с общей геометрией, цветом, сменой иконки и необязательной ссылкой. Проектный DIcon задаёт словарь значков и стандартные размеры. Icon не заменяет кнопку действия: для неё нужна кнопка с доступным именем.

## Основной API

- `src` — URL SVG или SVG-компонент; `component` — готовый компонент. `name` ищет файл в `public/icons` **проекта**, а не во внутреннем каталоге кита.
- `w`, `h` задают геометрию SVG; `rootW`/`rootH` и `root*` — отдельную геометрию/стиль корня при необходимости.
- `color`, `fill`, `stroke`, `strokeWidth`, `rotate` задают оформление; источник SVG должен поддерживать выбранный способ окраски.
- `hover` выбирает другой источник при наведении; `animate="swap"` — смена иконки. Сложные варианты — по типу IconProps.
- `href` включает ссылку; `tooltip` добавляет пояснение, но не заменяет доступное имя действия.

## Пример

```tsx
import { Icon } from '@delba/ui';

export function IconExample() {
  return <Icon src="/icons/arrow.svg" w={[24, 20, 24]} h={[24, 20, 24]}
    aria-hidden="true" />;
}
```

Предполагается реальный файл проекта `/icons/arrow.svg`. Значок декоративный; значимому значку задай имя, кнопке — имя самого действия.

## Приёмка

Проверь реальный источник, пропорции, состояние ошибки загрузки и различие hover/touch. При интерактивном использовании проверь семантику, фокус и доступное имя. Смена SVG сохраняет корневой ref и корректно завершает движение при reduced motion.

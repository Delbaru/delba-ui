# Flex

Текущий договор, сверенный по исходнику; runtime-проверка отдельно.

## Назначение и применение

Строка или колонка с гибким выравниванием, общей геометрией и motion. Подходит для композиции D-компонентов и семантических областей страницы. Не задаёт продуктовую тему или готовый скин карточки.

## Основной API

- `dir`, `wrap`, `align`, `justify`, `gap`, `rowGap`, `columnGap` управляют flex-раскладкой. Для одинакового значения во всех полосах указывай полный кортеж.
- `as` без ссылки выбирает тег (`div` по умолчанию, также `header`, `nav`, `section`, `ul` и другие из типа).
- `href` включает ссылку; `target`, `rel` и настройки перехода относятся к ней. Не вкладывай интерактивный контрол в ссылку целой карточки.
- `collapse={{ open, fade }}` раскрывает область; объектный `animate` управляет появлением/сменой содержимого. Смена содержимого: `animate={{ when: 'change', effect: 'fade', key, duration: 'fast' }}`; эффекты `up/down/scale` сохраняют направленный вход и зеркальный выход. Других motion-входов нет.
- `trackInteraction` / `onInteractionChange` учитывают активность области, включая дочерние порталы. `motionScope` задаёт источник hover-движения потомкам.
- `scrollFade` оформляет края уже прокручиваемого узла, сам по себе не ограничивает размер области.

## Пример

```tsx
import { Flex, Text } from '@delba/ui';

export function FlexExample() {
  return <Flex as="section" dir={['row', 'column', 'row']}
    align={['center', 'start', 'center']} gap={[24, 12, 16]}>
    <Text as="h2">Параметры</Text>
    <Text as="p">Размер и количество</Text>
  </Flex>;
}
```

## Приёмка

Проверь порядок и переносы на каждой полосе, семантический тег и отсутствие вложенных ссылок. Для motion проверь разворот и reduced motion; для interaction — фокус и дочерний портал. Маска scrollFade создаёт stacking context: оверлеи не должны обрезаться.

## Устройство и проверка рефакторинга

Корень сохраняет выбранный тег/ссылку, публичный ref, ui-flex и именованный маркер Flex из собственного SCSS-модуля. Ссылка, intent-prefetch, content swap, collapse и InteractionScope используют общие механизмы. Дополнительной DOM-обёртки ради модели или класса нет. `animation`, `transitionKey`, `reveal` и строковые/tuple-входы удалены; [миграция](../../../motion-migration.md) сохраняет событие и key.

Корень использует собственный styles.Name без глобального класса-дубля. Пустой селектор может исчезнуть при компиляции, поэтому наличие отдельного DOM-класса не гарантируется; фиктивные CSS-декларации для его сохранения запрещены. Проверка типов и unit-тесты не подтверждают внешний вид: финальная браузерная приёмка выполняется после объединения всей библиотеки.

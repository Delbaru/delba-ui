# Img

Текущий договор, сверенный по исходнику; runtime-проверка отдельно.

## Назначение и применение

Изображение поверх `next/image` с общей геометрией, art direction и сменой источника. Используй вместо повторения механики картинки в карточках; проектный компонент может фиксировать пропорции и оформление.

## Основной API

- `src` и `alt` обязательны. `src` принимает адрес, импорт файла или `[desktop, mobile, tablet]` источники.
- Автоматический `sizes` следует геометрии wrapper (`rootW`/`rootH` перекрывают `w`/`h`). Известные исходные размеры импорта учитывают дополнительную ширину bitmap при `cover`; для URL без metadata используется геометрия кадра.
- `null` в кортеже источников не создаёт свою `<source>`: итог определяется каскадом picture. Это особенность источников, не наследование layout-пропсов.
- Явный mobile, равный desktop, сохраняет приоритет перед отличающимся tablet:
  `[A, A, B]` выводит A на телефоне, B на планшете, A на desktop. `[A, null, B]`
  выводит B и на телефоне. Удалять mobile по одному равенству desktop нельзя.
- Для unoptimized источника единственный URL в `source.srcset` получает encoding
  ASCII-пробелов: SVG data URL с пробелами допустим в img.src, но иначе ломает
  разбор srcset. Готовый Next srcSet с несколькими кандидатами сохраняется целиком.
- `w`, `h`, `aspectRatio` задают геометрию; `objectFit`, `objectPosition` — содержимое. `rootW` / `rootH` отделяют размер корня.
- `sizes`, `sizesWidth`, `sizesHeight`, `quality` — оптимизация. Внешние URL требуют допуска в конфигурации Next приложения.
- `onLoad`, `onError` относятся к изображению; `animate` поддерживает смену источника. `href` делает картинку ссылкой и имеет приоритет над `fancybox`, чтобы избежать вложенных ссылок.
- Появление задаётся `animate={{ when: 'inView', effect: 'blur' }}`, смена источника — `animate={{ when: 'change', effect: 'fade' }}`. Строки, tuple и прежний `reveal` удалены; [миграция](../../../motion-migration.md) сохраняет ожидание загрузки нового кадра.

## Пример

```tsx
import { Img } from '@delba/ui';

export function ImgExample() {
  return <Img src="/images/printed-part.jpg" alt="Напечатанная деталь"
    w={[320, 280, 320]} h={[240, 210, 240]}
    objectFit={['cover', 'cover', 'cover']} />;
}
```

Адрес — файл приложения. Для декоративной картинки допустим пустой `alt`; значимая картинка требует описания.

## Приёмка

Проверь выбор кадра и размера на всех полосах, реальную загрузку и ошибку, отсутствие скачка геометрии. При смене источника старое изображение не исчезает до готовности нового; проверь быстрый повтор и reduced motion. Ссылка и lightbox не создают вложенные интерактивные элементы.

## Устройство после рефакторинга

`Img.tsx` показывает композицию и порядок событий: готовность изображения →
разрешение смены → пользовательский обработчик. `Img.model.ts` владеет корнем,
ссылкой/lightbox, общим motion/ref и готовностью текущего источника.
`Img.resource.ts` один раз подготавливает политику загрузки и каждый источник:
адрес → автоматический размер → оптимизация → Next props. Импорт `{ default: image }`
имеет тот же адрес для private API, lightbox и source identity, что обычный импорт.
`source-sizing.ts` сохраняет алгоритм геометрии; `optimization.ts` — правила приватных API
и native auto. `ImgContent`, `ImgBlur`, `ImgSwap` имеют свои папки/SCSS и используют
существующие DOM-узлы; дополнительных обёрток нет.

`swap/useImgSwap.ts` владеет снимками кадров, ожиданием загрузки, очередью последнего
источника и очисткой таймера. Рендер слоёв принадлежит `ImgSwap`. Готовность blur
принимает событие только актуального источника: поздний `load` уходящего кадра
не возвращает размытие поверх уже загруженного нового. `error` завершает ожидание
смены и вызывает пользовательский обработчик, сохраняя прежнюю политику blur.

`data-hide-scrollbar`, `data-order-*`, `data-fancybox-*`, `data-carousel-*` идут на корень;
остальные native props и события — на изображение. `href` исключает вложенный lightbox.
Responsive-скрытие задаётся `hide={[desktop, mobile, tablet]}` на корневой коробке.
Legacy `data-hide-mobile/tablet/pc/desktop` не является договором Img.
Art direction сохраняет порядок mobile → tablet; `priority` означает eager/high,
а явный `preload` продолжает управляться Next. Ручные `sizes` в потребителях не добавляются.

Регрессии: `Img/tests/Img.resource.test.ts`, `Img/tests/source-sizing.test.ts`,
`tools/tests/images.test.ts`. Браузерный сценарий `Img object change animate` проверяет
ожидание, поздний load старого кадра, blur, направление, очередь и очистку слоёв.

Собственный Img.module.scss объявляет корень Img. Существующие ui-img-* классы
сохраняют договор темы и генерации; именованный маркер дополняет их без новой обёртки.
Смена источника использует animate={{ when: 'change', effect: 'fade' }}.
Строковые и tuple-входы удалены из типов и decoder; observer и source-swap
по-прежнему используют общие механизмы.

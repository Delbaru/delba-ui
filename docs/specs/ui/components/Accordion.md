# Accordion

Группа раскрываемых разделов: FAQ, инструкции, дополнительные сведения.
Используй, когда заголовки должны оставаться видны при закрытом содержимом.
Проектный D-компонент задаёт оформление, кит — выбор, клавиатуру и сворачивание.

## Основной договор

| Проп | Значение |
|---|---|
| `multiple` | По умолчанию не включён: открыт максимум один пункт |
| `value` / `defaultValue` | Один ключ или `null`; при `multiple` — массив ключей |
| `onValueChange` | Новый ключ/`null` или массив в соответствии с режимом |
| `collapsible` | `true`: повторный клик закрывает единственный пункт; в multiple не влияет |
| `headingAs` | Уровень заголовков, по умолчанию `h3` |
| `indicator` | Общий индикатор; оформление открытого состояния задаёт проект |

`value !== undefined` включает controlled-режим. Без value начальный выбор
берётся из defaultValue; по умолчанию все пункты закрыты.
Дочерние разделы создаются через [AccordionItem](AccordionItem.md).

## Пример

```tsx
'use client';
import { useState } from 'react';
import { Accordion, AccordionItem } from '@delba/ui';

export function Help() {
  const [value, setValue] = useState<string | null>(null);
  return <Accordion value={value} onValueChange={setValue}>
    <AccordionItem value="files" trigger="Какие файлы подходят?">
      Подготовьте модель в поддерживаемом формате.
    </AccordionItem>
    <AccordionItem value="delivery" trigger="Как получить заказ?">
      Выберите доставку при оформлении.
    </AccordionItem>
  </Accordion>;
}
```

## Состояния и ограничения

Ключи пунктов уникальны в группе. Открытые пункт, триггер и панель получают
`state~='open'`. Панели сохраняются для поиска; найденный браузером текст
может раскрыть раздел. Стрелки/Home/End перемещают фокус между доступными
триггерами своей группы; вложенная группа имеет отдельную навигацию.

## Устройство и владельцы

`Accordion.tsx` соединяет Flex и контекст из `useAccordion`. Модель владеет
выбором, навигацией своей группы и отменяемым удержанием триггера при сворачивании.
Пункт использует `selection.isOpen/toggle/reveal` и `position.hold`; он не ищет
корень и не хранит вторую копию открытых значений. Корень имеет маркер `Accordion`
и собственный Accordion.module.scss.

## Приёмка

Проверь single/multiple, повторный клик, controlled-обновление и disabled-пункт.
Клавиатура не должна захватывать вложенную группу; поиск по закрытому тексту
проверяется в поддерживающем браузере. Проверь быстрый разворот и reduced motion.

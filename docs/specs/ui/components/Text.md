# Text

Текущий договор, сверенный по исходнику; runtime-проверка отдельно.

## Назначение и применение

Текст с семантическим тегом, типографической ролью и общим движением. Для редакторского HTML/документа используй [LexicalText](LexicalText.md). Проектные роли и типографические пресеты принадлежат теме/DText потребителя.

## Основной API

- `as` задаёт тег (`div` по умолчанию). `variant` задаёт вид, а не семантику; по умолчанию роль `body` на всех полосах.
- `as="label"` вместе с `htmlFor` связывает подпись с нативным полем. Input
  использует этот договор через внутренний FieldFrame.
- `variant` принимает роли кита, имена типографики проекта и `inherit` для фрагмента внутри чужого текста. Имена проекта должны быть объявлены в его UI config.
- `fontSize`, `fontWeight`, `lineHeight`, `letterSpacing`, `textAlign`, `whiteSpace` — точечные настройки; повторяемые наборы выносятся в проектный договор.
- `rows` ограничивает число строк; `ellipsis` — сокращение. Полный текст должен оставаться доступным там, где влияет на решение.
- `href` делает текст ссылкой; `format` форматирует содержимое. `animate` объединяет появление и эффекты текста, `collapse` — раскрытие блочного текста.

Смена значения: `animate={{ when: 'change', effect: 'textSlide', by: 'text', duration: 'fast' }}`. Для последовательности: `animate={{ when: 'change', effect: 'textClip', steps, currentStep, duration: 'normal' }}`; тот же договор с effect textSlide выбирает сдвиг шагов. Публичный вход только объектный; `animation`, строковые/tuple-формы и их responsive-варианты удалены. [Миграция](../../../motion-migration.md) сохраняет существующий renderer.

## Пример

```tsx
import { Text } from '@delba/ui';

export function TextExample() {
  return <>
    <Text as="h2" variant={['h2', 'h2', 'h2']}>Ваш заказ</Text>
    <Text as="p">Параметры и стоимость печати</Text>
  </>;
}
```

## Приёмка

Тег и порядок заголовков соответствуют смыслу, роль читается на каждой полосе. Проверь длинное значение, переносы, сокращение и отсутствие потери обязательного смысла. Для эффектов — замену текста, быстрое обновление и reduced motion; типизация не подтверждает визуальное качество.

## Устройство и проверка рефакторинга

Корневой текстовый узел получает маркер Text и собственный Text.module.scss. Семантика, ссылки и типографика остаются у Text; реестр выбирает визуальный эффект. TextSlide — DOM-free диспетчер; TextSlideSequence, TextSlideHover, TextSlideSwap и TextRevealLayer находятся в именованных папках со своими SCSS и корневыми маркерами. Простой span буквы не выделяется в компонент. CollapsibleText не создаёт DOM: удерживает прежний React-контент и передаёт collapse существующему CollapseWrap.

Корень использует собственный styles.Name без глобального класса-дубля. Пустой селектор может исчезнуть при компиляции, поэтому наличие отдельного DOM-класса не гарантируется; фиктивные CSS-декларации для его сохранения запрещены. Проверка типов и unit-тесты не подтверждают внешний вид: финальная браузерная приёмка выполняется после объединения всей библиотеки.

Для посимвольной волны доступен `animate={{ when: 'change', effect: 'textReveal', duration: 'fast', stagger: 'step' }}`; hover-слайд использует `animate={{ when: 'hover', effect: 'textSlide' }}`. Настройки превращаются в опции существующего реестра, а не запускают дополнительную анимацию. Последовательности textSlide/textClip измеряют шаги через ResizeObserver своего документа: высота уточняется после загрузки шрифта и переноса строк. Повторяющиеся подписи шагов допустимы; их React-ключи определяются позицией, а не обрезанным текстом.

Финальная проверка последовательностей: одинаковые подписи, быстрый переход через несколько шагов, resize во время смены, отложенный шрифт, reduced motion и unmount посреди перехода.

В последовательностях textSlide/textClip невыбранные шаги получают aria-hidden; доступное дерево содержит только текущую подпись. Изменение шага остаётся внешним выбором потребителя, эффект управляет лишь фазой отображения.

# CarouselDots

Статус требований: базовый договор. Основание — чтение исходников;
runtime-проверка не выполнялась в рамках карточки.

## Назначение и выбор

Пагинация [Carousel](Carousel.md): точки либо собственные миниатюры страниц.
Используй для прямого выбора страницы и отображения текущего положения.
Для перехода назад/вперёд есть [CarouselNav](CarouselNav.md).

## Основной договор

- `carouselId` явно связывает контрол с одноимённой каруселью.
  Без него контрол ищет ближайшую подходящую карусель через DOM.
- Видимость задаётся на Carousel: `navigation="dots"` / `"both"` либо `pagination`.
  При нескольких лентах указывай идентификатор явно.
- `renderItem({ index, isActive, onSelect })` заменяет точку своим содержимым.
  Renderer сам создаёт доступную кнопку, имя, активное состояние и обработчик.
- Остальные пропсы наследуются от `Flex`, кроме `children`.
  По умолчанию настроены горизонтальный ряд, центрирование и desktop-gap 8.
- `index` — индекс страницы от нуля; число точек определяется страницами,
  оно не обязано совпадать с числом исходных слайдов.

## Минимальный пример

```tsx
'use client';
import { Carousel, CarouselDots } from '@delba/ui';

export function Gallery() {
  return <section>
    <Carousel carouselId="photos" pagination={[true, true, true]}>
      <div>Фото 1</div><div>Фото 2</div>
    </Carousel>
    <CarouselDots carouselId="photos" />
  </section>;
}
```

## Состояния и ограничения

Кнопок нет, пока карусель не найдена, пагинация выключена или страница одна.
Обёртка Flex при этом остаётся. Текущая точка обновляется также после drag и стрелок.
Стандартная кнопка имеет `aria-label` и `aria-current`; собственный renderer
не получает эту семантику автоматически.

## Критерии приёмки

Проверь привязку среди двух каруселей, переход мышью и клавиатурой, активную страницу
после drag и resize, отсутствие лишних кнопок для одной страницы.
Для миниатюр проверь доступное имя и вызов переданного `onSelect`.

## Владение и оформление

CarouselDots использует общий controls registry для Carousel и NativeCarousel.
Он не хранит собственный индекс и вызывает только snapshot.api.goTo. Свои
CarouselDots.module.scss и класс CarouselDots; тексты кнопок — messages.carousel.goTo.
Подписка принадлежит документу корня; замена найденной карусели переподключает её.

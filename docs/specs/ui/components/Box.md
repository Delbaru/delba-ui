# Box

Текущий договор, сверенный по исходнику; браузерная проверка этой страницей не подтверждается.

## Назначение и применение

Нейтральный `div` с общими layout-пропсами, прокруткой, раскрытием и сменой содержимого. Используй для контейнера без специальной семантики. Для строки или колонки удобнее [Flex](Flex.md), для сетки — [Grid](Grid.md). Проектная роль и скины принадлежат D-компоненту потребителя; пустая обёртка над Box не обязательна.

## Основной API

- `children`, DOM-атрибуты и `ref` относятся к внутреннему `div`.
- `container` включает общую ширину и поля контейнера; `p`, `w`, `h`, `bg`, радиусы и прочая геометрия — из общей коробки.
- `scroll="x" | "y" | "both"` включает нативную прокрутку. Размер области нужно ограничить.
- `collapse={{ open, fade, keepMounted }}` выражает раскрытие; состоянием `open` владеет вызывающий компонент.
- `animate={{ when: 'load', effect: 'fade' }}` — появление; `animate={{ when: 'change', effect: 'fade', key, duration: 'fast' }}` — последовательная смена содержимого. Не подменяй ключ ручным таймером удаления.
- Публичный motion принимает только объектный `animate`; отдельный `reveal` и строки/tuple удалены. Направленные change-эффекты `up/down/scale` используют тот же content-swap. См. [миграцию](../../../motion-migration.md).
- Responsive-кортеж: `[desktop, mobile, tablet]`; `null` пропускает полосу, а не наследует desktop.

## Пример

```tsx
'use client';
import { useState } from 'react';
import { Box, Button } from '@delba/ui';

export function BoxExample() {
  const [open, setOpen] = useState(false);
  return <>
    <Button type="button" aria-expanded={open} onClick={() => setOpen(!open)}>
      Подробности
    </Button>
    <Box collapse={{ open, fade: true }}><p>Условия заказа</p></Box>
  </>;
}
```

В приложении кнопку заменяет его DButton. Для заголовка/футера вне скролла выделяй отдельные соседние узлы.

## Приёмка

Проверь геометрию всех полос, открытие/закрытие, быстрый разворот, reduced motion и сохранение содержимого до ухода. Прокрутка не должна захватывать неподвижный footer; ref не должен внезапно указывать на клип анимации.

## Устройство и проверка рефакторинга

Корневой div сохраняет публичный ref и классы ui-box; собственный модуль Box.module.scss и маркер Box позволяют найти компонент в DOM. Геометрия, shared motion, content swap и collapse используют существующих владельцев ядра/хуков, без отдельной модели ради переименования вызовов. Объектный change/fade использует тот же useContentMotion, что Flex; duration доходит до фактического CSS-перехода.

Именованный класс дополняет существующие ui-* классы без изменения семантического DOM. Пустой селектор может удаляться CSS Modules; явный маркер сохраняет имя без фиктивных CSS-деклараций. Проверка типов и unit-тесты не подтверждают внешний вид: финальная браузерная приёмка выполняется после объединения всей библиотеки.

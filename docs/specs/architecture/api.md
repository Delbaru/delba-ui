# Публичный API и совместимость

Статус: базовый договор. Область: exports, props, refs, события и переход потребителей.

Для новых controller/команд действует [договор читаемости](readable-api.md):
понятный публичный вход, один владелец механизма и однократная настройка реакций.
Согласовано направление прямого импорта `toast` с однократным provider, но
новый export и поведение нескольких providers требуют реализации и приёмки;
текущий API `useToast().show` не объявляется уже заменённым.

Канонический подробный договор — [authoring §3.1](../../authoring.md#31-единый-договор-api),
список входов и договор темы — [README](../../../README.md).

Изменение API описывает намерение, владельца состояния, значения по умолчанию,
конфликтующие формы и наблюдаемый результат. Публичные props имеют JSDoc;
обычный DOM ref не подменяется ручкой команд. Пользовательские обработчики
сохраняются и компонуются с общей механикой, включая отмену и cleanup.

Команды должны быть типизированы, называться по действию и документировать
наблюдаемый эффект. Каталог команд, видов или регистраций определяет их в одном
месте у владельца механики; потребители используют этот контракт, а не копируют
списки. Не передавай библиотечному компоненту объект сайта/CMS целиком: принимай
только минимальные значения, необходимые для общей механики.

Controlled- и uncontrolled-режимы не создают двух владельцев состояния.
Responsive-кортеж `[desktop, mobile, tablet]` и пропуск `null` сохраняют договор.
Неиспользование API одним потребителем не доказывает возможность удаления.
Ломающее изменение требует явного описания миграции и проверки потребителей;
совместимые старые формы не исчезают в рамках обычного рефакторинга.

Предметная спецификация фиксирует изменение договора, а не переписывает весь
справочник props. Приёмка: типы, exports, DOM/ref, события, SSR и сценарий
потребителя по [acceptance](../verification/acceptance.md). При рефакторинге
сверяй целый путь потребителя и внутреннюю реализацию: короткий вызов сам по себе
не подтверждает понятность или отсутствие повторной механики.
